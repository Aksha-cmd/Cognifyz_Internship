# Cognifyz Data Science Internship Portfolio

Welcome to my repository containing the complete, multi-level data science project completed during my internship with Cognifyz IT Solutions. This project focuses on predictive analytics, operational feature relationships, geospatial mapping, and machine learning workflows.

## 🚀 Project Architecture

### 📊 Level 1: Data Exploration & Preprocessing
* Cleaned and preprocessed raw datasets, handled missing values, and corrected data types.
* Performed descriptive statistical analysis on restaurant metrics.
* Analyzed the distribution of the target variable and identified cuisine and city trends.

### ⚙️ Level 2: Table Booking & Feature Analysis
* Analyzed the relationship between online delivery, table booking availability, and user ratings.
* Investigated how price ranges correlate with table booking options.
* Determined which price levels offer the highest average ratings and mapped restaurant distributions geographically.

### 🤖 Level 3: Predictive Modeling & Insights
* Built robust regression pipelines to predict aggregate ratings using Scikit-Learn.
* Evaluated models using Mean Squared Error ($MSE$) and $R^2$ scores.
* Created final comparative charts to track actual vs. predicted model outcomes.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** VS Code / Jupyter Notebooks
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
