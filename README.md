# Cognifyz Data Science Internship Portfolio

Welcome to my repository containing the complete, multi-level data science project completed during my internship with Cognifyz IT Solutions. This project focuses on predictive analytics, text mining, geospatial analysis, and machine learning workflows on real-world restaurant datasets.

## 🚀 Project Architecture

### 📊 Level 1: Data Exploration & Preprocessing
* Cleaned and preprocessed raw datasets, handled missing values, and corrected data types.
* Performed descriptive statistical analysis on restaurant metrics.
* Analyzed class imbalances and distributions of target variables (Aggregate Ratings).

### ⚙️ Level 2: Advanced Analysis & Feature Engineering
* Engineered text-processing routines to extract common cuisine combinations.
* Analyzed geospatial data to map restaurant distributions across cities.
* Investigated correlations between price ranges, online delivery options, and user ratings using Seaborn/Matplotlib visualizations.

### 🤖 Level 3: Predictive Modeling & Insights
* Built robust regression pipelines to predict aggregate ratings using Scikit-Learn.
* Evaluated models using Mean Squared Error ($MSE$) and $R^2$ scores.
* Created final comparative charts to track actual vs. predicted model outcomes.

## 🛠️ Tech Stack & Libraries
* **Language:** Python
* **Environment:** VS Code / Jupyter Notebooks
* **Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
